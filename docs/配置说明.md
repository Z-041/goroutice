# 配置说明

应用使用 YAML 配置文件（默认 `config.yaml`），并通过 [Viper](https://github.com/spf13/viper) 加载。

**密钥类配置不写进配置文件**：数据库口令、JWT 密钥、SMTP 账号口令、初始管理员口令、更新令牌一律留空，由环境变量或 `.env` 注入。这样 `config.yaml` 可以安全地提交与推送。

## 配置来源与优先级

```
进程环境变量  >  .env 文件  >  config.yaml  >  代码内置默认值
```

- **环境变量**：前缀 `BLOG_`，层级用下划线连接，`config.yaml` 里任意键都可覆盖。
- **`.env` 文件**：启动时自动加载，查找顺序为「可执行文件所在目录 → 当前工作目录」，取第一个存在的文件；文件中已存在的进程环境变量优先，不会被覆盖。
  该文件已在 `.gitignore` 中，**不要提交**。
  生产部署请把它放在 `server.exe` 同目录（自更新只替换二进制、不改变其位置）；`go run ./cmd/server` 时放在仓库根目录即可。

### 密钥类环境变量一览

| 配置项 | 环境变量 | 说明 |
| --- | --- | --- |
| `database.password` | `BLOG_DATABASE_PASSWORD` | MySQL 口令 |
| `jwt.secret` | `BLOG_JWT_SECRET` | JWT 签名密钥，至少 16 字符，缺失或为空时拒绝启动 |
| `smtp.username` | `BLOG_SMTP_USERNAME` | 发信账号 |
| `smtp.password` | `BLOG_SMTP_PASSWORD` | 发信密码/授权码 |
| `bootstrap.admin_password` | `BLOG_BOOTSTRAP_ADMIN_PASSWORD` | 初始管理员口令，仅在库中还没有该管理员时生效 |
| `updater.github_token` | `BLOG_UPDATER_GITHUB_TOKEN` | GitHub API 令牌，公开仓库可留空 |
| `updater.gitee_token` | `BLOG_UPDATER_GITEE_TOKEN` | Gitee `access_token` |

其余配置项同样可用环境变量覆盖，命名规则为 `BLOG_` + 键名（`.` → `_`，全大写）：

| 配置项 | 环境变量 |
| --- | --- |
| `database.host` | `BLOG_DATABASE_HOST` |
| `server.trusted_proxies` | `BLOG_SERVER_TRUSTED_PROXIES`（列表用英文逗号分隔） |
| `security.password_min_length` | `BLOG_SECURITY_PASSWORD_MIN_LENGTH` |
| `cors.allowed_origins` | `BLOG_CORS_ALLOWED_ORIGINS`（列表用英文逗号分隔） |

### 三种设置方式

1. **`.env` 文件（推荐）**：与 `config.yaml` 同级或 exe 同目录，每行 `KEY=VALUE`，支持 `#` 注释、空行、`export` 前缀与成对引号：

```dotenv
BLOG_DATABASE_PASSWORD=your-db-password
BLOG_JWT_SECRET=please-use-a-long-random-secret
```

2. **系统环境变量**：Windows 下 `setx BLOG_JWT_SECRET "..."`（对新开的进程生效），或写进 Windows 服务的环境变量配置；Linux 下写进 systemd unit 的 `Environment=` / `EnvironmentFile=`。

3. **进程内临时指定**：`$env:BLOG_SMTP_ENABLED="false"; go run ./cmd/server`（仅当前会话有效）。

> 空字符串的环境变量等同于「未设置」，不会覆盖配置文件里的值。

## 完整配置示例

```yaml
server:
  port: 8080
  mode: debug
  read_timeout: 30
  write_timeout: 30
  idle_timeout: 60
  max_body_size: 16777216
  trusted_proxies: []

database:
  host: 127.0.0.1
  port: 3306
  username: root
  password: "" # 环境变量 BLOG_DATABASE_PASSWORD
  dbname: blog
  charset: utf8mb4
  parse_time: true
  loc: Local
  max_idle_conns: 0
  max_open_conns: 0
  conn_max_lifetime_minutes: 0

jwt:
  secret: "" # 环境变量 BLOG_JWT_SECRET
  access_expire_minutes: 15
  refresh_expire_hours: 720
  issuer: "goroutice-blog"

upload:
  path: "uploads"
  max_size: 10485760
  allowed_exts: [".jpg", ".jpeg", ".png", ".gif", ".webp", ".svg", ".pdf", ".txt", ".md", ".zip"]

ratelimit:
  rps: 5
  burst: 10
  write_rps: 20
  write_burst: 40

security:
  max_login_attempts: 5
  login_lock_minutes: 15
  email_verification_enabled: true
  password_min_length: 8
  password_require_uppercase: false
  password_require_special: false

smtp:
  enabled: false
  host: "smtp.example.com"
  port: 587
  username: "" # 环境变量 BLOG_SMTP_USERNAME
  password: "" # 环境变量 BLOG_SMTP_PASSWORD
  from: "no-reply@example.com"
  from_name: "Goroutice Blog"
  use_tls: false
  insecure_skip_verify: false

cors:
  allowed_origins: ["*"]

bootstrap:
  admin_username: admin
  admin_password: "" # 环境变量 BLOG_BOOTSTRAP_ADMIN_PASSWORD
  admin_email: "admin@example.com"

updater:
  enabled: false
  interval_minutes: 5
  github_owner: ""
  github_repo: ""
  github_token: "" # 环境变量 BLOG_UPDATER_GITHUB_TOKEN
  gitee_owner: ""
  gitee_repo: ""
  gitee_token: "" # 环境变量 BLOG_UPDATER_GITEE_TOKEN

site:
  base_url: "http://localhost:8080" # 对外访问域名，用于生成 RSS/sitemap 绝对链接
  title: "Goroutice Blog" # RSS channel 标题
  description: "Goroutice Blog" # RSS channel 描述
  language: "zh-CN" # RSS language 字段

article:
  revision_keep: 20 # 每篇文章保留的历史修订条数，0 = 不记录修订历史
  view_dedup_minutes: 30 # 浏览量去重窗口（分钟），0 = 使用默认值 30
```

## 配置项详解

### server —— HTTP 服务

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `port` | int | 8080 | 监听端口 |
| `mode` | string | `debug` | Gin 运行模式：`debug`/`release`/`test` |
| `read_timeout` | int | 30 | 读取请求超时（秒） |
| `write_timeout` | int | 30 | 写入响应超时（秒） |
| `idle_timeout` | int | 60 | 空闲连接超时（秒） |
| `max_body_size` | int64 | 16777216 | 请求体大小上限（字节，默认 16MB） |
| `trusted_proxies` | []string | `[]` | 可信反向代理 IP/CIDR；为空表示不信任 `X-Forwarded-For` 等代理头（限流按真实对端 IP 分桶） |

### database —— MySQL 连接

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `host` | string | 127.0.0.1 | 主机 |
| `port` | int | 3306 | 端口 |
| `username` | string | root | 用户名 |
| `password` | string | 无（环境变量） | 口令，由 `BLOG_DATABASE_PASSWORD` 注入 |
| `dbname` | string | blog | 数据库名 |
| `charset` | string | utf8mb4 | 字符集 |
| `parse_time` | bool | true | 是否解析 time 类型 |
| `loc` | string | Local | 时区 |
| `max_idle_conns` | int | 0 | 最大空闲连接，0=自动（CPU 核数） |
| `max_open_conns` | int | 0 | 最大打开连接，0=自动（CPU 核数 × 4） |
| `conn_max_lifetime_minutes` | int | 0 | 连接最大存活（分钟），0=自动（30） |

### jwt —— 鉴权

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `secret` | string | 无（必填） | JWT 签名密钥，至少 16 字符；缺失或为空时拒绝启动 |
| `access_expire_minutes` | int | 15 | access token 时效（分钟） |
| `refresh_expire_hours` | int | 720 | refresh token 时效（小时，30 天） |
| `issuer` | string | goroutice-blog | JWT 签发者 |

### upload —— 文件上传

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `path` | string | uploads | 存储目录 |
| `max_size` | int64 | 10485760 | 单文件大小上限（字节，10MB） |
| `allowed_exts` | []string | 见示例 | 允许的扩展名白名单 |

### ratelimit —— 接口限流（令牌桶，分档）

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `rps` | float64 | 5 | 认证类接口每秒放行令牌数（默认档） |
| `burst` | int | 10 | 认证类接口令牌桶容量 |
| `write_rps` | float64 | 20 | 写接口每秒放行令牌数 |
| `write_burst` | int | 40 | 写接口令牌桶容量 |

> 限流按「档位 + 用户/IP + 接口路径」分桶计数。详见 [架构与设计.md](架构与设计.md)。

### security —— 安全加固

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `max_login_attempts` | int | 5 | 连续登录失败次数阈值 |
| `login_lock_minutes` | int | 15 | 触发锁定后的锁定分钟数 |
| `email_verification_enabled` | bool | true | 注册后是否需要邮箱验证 |
| `password_min_length` | int | 8 | 密码最小长度 |
| `password_require_uppercase` | bool | false | 是否强制要求大写字母 |
| `password_require_special` | bool | false | 是否强制要求特殊字符 |

### smtp —— 邮件发送

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | false | `true` 使用真实 SMTP；`false` 使用日志邮件（开发用） |
| `host` | string | localhost | SMTP 服务器 |
| `port` | int | 25 | 端口：587(STARTTLS)/465(隐式 TLS) |
| `username` | string | 无（环境变量） | 发信账号，由 `BLOG_SMTP_USERNAME` 注入 |
| `password` | string | 无（环境变量） | 发信密码/授权码，由 `BLOG_SMTP_PASSWORD` 注入 |
| `from` | string | no-reply@example.com | 发件人邮箱 |
| `from_name` | string | Goroutice Blog | 发件人显示名称 |
| `use_tls` | bool | false | `true`=隐式 TLS（465）；`false`=STARTTLS（587） |
| `insecure_skip_verify` | bool | false | 跳过 TLS 证书校验（仅自建/测试） |

### cors —— 跨域

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `allowed_origins` | []string | `["*"]` | 允许的来源，生产建议改为具体域名 |

### bootstrap —— 初始化管理员

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `admin_username` | string | admin | 默认管理员用户名 |
| `admin_password` | string | 无（环境变量） | 初始管理员口令，由 `BLOG_BOOTSTRAP_ADMIN_PASSWORD` 注入；仅在库中还没有该管理员时用于创建，此时若为空会拒绝启动 |
| `admin_email` | string | admin@example.com | 默认管理员邮箱 |

> 仅在数据库中不存在同名管理员时才会创建；已存在则跳过。

### updater —— 在线自动更新

服务端自更新：按 `interval_minutes` 周期轮询主备源的 Release，发现更高版本后下载当前平台产物、校验 SHA256，通过则原子替换二进制并重启自身。管理端可通过 `GET /api/v1/admin/updater` 查看状态、`POST /api/v1/admin/updater/check` 手动检查（仅 admin，见 [API.md](API.md)）；**升级本身始终由后台自动完成，不提供手动触发接口**。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | false | `true` 时启动后台更新轮询 |
| `interval_minutes` | int | 5 | 轮询间隔（分钟）；≤0 时回退为 5 分钟 |
| `github_owner` | string | "" | GitHub 主源 owner（用户名或组织名） |
| `github_repo` | string | "" | GitHub 主源仓库名 |
| `github_token` | string | "" | GitHub API 令牌，经 `Authorization: Bearer` 发送；公开仓库可留空 |
| `gitee_owner` | string | "" | Gitee 备用源 owner |
| `gitee_repo` | string | "" | Gitee 备用源仓库名 |
| `gitee_token` | string | "" | Gitee `access_token`，作为查询参数拼接；留空则不附带该参数 |

**来源生效条件**：`owner` 与 `repo` **同时非空**才会被注册为一个来源。因此

- `enabled: true` 且两个来源都未配置完整时，进程会**因配置校验失败直接退出**（启动即报 `init updater`），不会静默跳过；
- 只配置 GitHub 也可正常工作，Gitee 仅为备用，主源不可用时自动切换。

**版本与触发条件**

- 当前版本取自二进制内注入的 `main.version`（CI 通过 `go build -ldflags "-X main.version=v1.2.3"` 写入），**不是**配置文件项；
- 没有注入版本时（本地 `go build` / `go run`）回退为 `dev+<短提交>`（工作区有未提交改动时追加 `-dirty`），取自编译器写入的 VCS 信息，便于事后定位线上二进制对应哪个提交；
- 当前版本不是合法语义化版本（如 `dev`、`dev+674b364`）时，自动更新**不生效**：状态接口返回 `enabled: false`，`last_error` 说明原因，后台也不会轮询 Release 接口；
- 仅当远端 `tag_name` **严格大于**当前版本时才下载；同一版本存在主备两个来源时，并发测速后选响应最快的一个下载。

**对 Release 资产的要求**（不满足则该来源会被跳过）

- 必须存在文件名以 `-{GOOS}-{GOARCH}{扩展名}` 结尾的产物，例如 `myapp-1.2.3-windows-amd64.exe`；扩展名仅在 Windows 平台默认 `.exe`；
- 必须同时上传 `checksums.txt`，且其中包含该产物的 SHA256（兼容 `<hash>  <file>`、`<hash> *<file>`、`SHA256 (file) = <hash>` 三种写法）；
- 校验不通过时临时文件会被立即删除，本轮更新放弃，不影响下一次轮询。

> 升级过程中会先把旧二进制重命名为 `.old` 备份再替换，新进程启动失败会自动回滚；成功后旧进程退出并保留 `.old` 文件供排查。
>
> **安全提示**：`github_token` / `gitee_token` 建议通过环境变量 `BLOG_UPDATER_GITHUB_TOKEN` / `BLOG_UPDATER_GITEE_TOKEN` 注入，不要写入 `config.yaml`。

### site —— 站点信息（订阅与索引）

仅用于生成 `/feed.xml`、`/sitemap.xml`、`/robots.txt` 三个根路径公开资源，不影响 API 行为。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `base_url` | string | http://localhost:8080 | 站点对外地址，用于拼接订阅/索引里的**绝对链接**（结尾斜杠会被去掉）；对外部署必须改成真实域名 |
| `title` | string | Goroutice Blog | RSS `channel.title` |
| `description` | string | Goroutice Blog | RSS `channel.description` |
| `language` | string | zh-CN | RSS `language` |

### article —— 文章相关

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `revision_keep` | int | 20 | 每篇文章保留的历史修订条数；`0` 表示**不记录**修订历史（更新时不再写快照） |
| `view_dedup_minutes` | int | 30 | 浏览量去重窗口（分钟）；同一来源（IP + `User-Agent`）在该窗口内重复打开同一篇文章只计一次。`0` 或负值表示使用内置默认值 30 |

> 修订在每次 `PUT /api/v1/articles/:id` 与回滚操作时写入，超出 `revision_keep` 的旧版本会被自动裁剪（保留版本号较大的那批）。
> 浏览量去重状态保存在进程内存中，由后台任务每分钟清理一次过期记录；调整 `view_dedup_minutes` 后需重启生效。
> 全文检索索引无需配置：启动时会自动探测 MySQL 8.0 的 `articles` 表，缺少 `ft_article`（`WITH PARSER ngram`）时自动创建；创建失败（如权限不足）只记录警告并降级为 `LIKE` 检索，不阻塞启动。
